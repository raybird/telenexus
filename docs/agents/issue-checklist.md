# Issue 建檔快速檢查清單

new-issue 完成前逐項確認；本檔只查文件完整性，實作證據由 execute-task 取得。

- [ ] issue ID、核心目標、最小範圍與必要決策明確；建立目錄與連結正確。
- [ ] 依 AGENTS.md 分開判定規模／風險，必要文件齊備，未觸發的分析文件不建立。
- [ ] README 有分級、風險、實際狀態與建立日期；風險策略引用唯一來源。
- [ ] 依 [acceptance.md](acceptance.md) 核對驗收形式、可觀察結果、重要失敗路徑與核准來源。既有明確要求可作來源，不需形式上的重複問答。
- [ ] 核准紀錄覆蓋所有現存條件；分批門檻成立、待核准項有等待原因，且未被排成可執行 Task。
- [ ] 任務有唯一來源、穩定編號、產出、相依與可檢查完成判準；Large 需細化部分已留在原計畫供 decompose 處理。
- [ ] 依 [verification.md](verification.md) 規劃合適測試層級／等價證據；觀測式 AC 有失敗差異與對照組計畫，不把尚未取得的觀測寫成通過。
- [ ] 阻塞未知已解決；其他未知與 gate 豁免有來源、影響及真實狀態。
- [ ] 已讀 [project.md](project.md)，納入實際需要的專案 gate 與常青文件更新。
- [ ] Timeline 記語意事件的實際日期，沒有重複任務狀態或另加檔尾 Changelog。
