## 步驟

1. ✅ **評估集與量測工具（AC-1）**
   - 做法：
     - 在 `~/.cache/telenexus-issue19/` 以 Memoria 1.28.1 映像建立索引並啟動服務。
     - 從 `user:` 分區的對話出相關題、標註目標 session；出無關題，並用關鍵字搜尋確認副本裡沒有相關內容。
     - 依題目編號的雜湊切成調整集與驗收集（約 2:1），凍結並記錄 sha256。
     - 把抽查樣本交給使用者確認。
     - 量測腳本：`evidence/scripts/` 下，讀凍結的題目檔，對服務發 recall，把每題的原始結果（hits、confidence、snippet 雜湊）存在私人目錄，再以各候選判準重算命中與注入。
   - 完成判準：凍結雜湊、抽查結果、現行判準在調整集上的基準數字都寫進 `evidence/step1-evaluation-set.md`。
   - 相依：驗收條件核准。
2. ✅ **候選判準（AC-2）**：第一版未達門檻，依規格修訂做第二版，在全新驗收集通過
   - 做法：只用調整集比較候選判準，例如：
     - 門檻；
     - 重算覆蓋率時排除純數字與泛用詞的 token；
     - 要求命中的 token 數不少於某個值；
     - 以上的組合。
     - 也試問句前處理，例如送出前去掉純數字 token。這需要重新呼叫 Memoria。
   - 選定後，驗收集只跑一次。
   - 完成判準：`evidence/step2-criteria.md` 列出每個候選判準的兩個數字，以及選定判準在驗收集上的結果；達不到門檻時記錄最佳取捨並請使用者決定。
   - 相依：步驟 1。
